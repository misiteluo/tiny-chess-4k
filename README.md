A 4 KB chess engine in Python: 0x88 board, alpha-beta search with null-move pruning, quiescence, a transposition table, and tapered piece-square evaluation, packed with lzma + base85. Practice Elo around 1,200 on the make.fun tiny-chess-01 gauntlet.

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 main.py
```
